BOOTH Library
for Unity

BOOTH Library Managerの商品をUnityの中で探す。商品画像、タグ、商品ページ、取り込んだアセットをつなぎます。

0.3.0-preview.1 · Windows · Unity 2022.3 · MIT
VCC / ALCOM に追加 ZIPをダウンロード

使い始める

  1. VCC / ALCOMにリポジトリを追加し、先行版パッケージの表示を有効にします。
  2. プロジェクトに BOOTH Library for Unity を追加します。
  3. Unityの Window → HoriCraft → BOOTHライブラリ を開きます。
リポジトリURLを手動で追加する

https://horicraft.github.io/vpm/booth-library-unity/index.json

ZIPから導入する

ZIPを展開し、中身をプロジェクトの Packages/com.horicraft.booth-library-unity/ に置きます。package.json がこのフォルダーの直下にある状態にしてください。

パッケージを取り込む

商品詳細の「BLMの保存先」からエクスプローラーを開き、目的の .unitypackage をダブルクリックします。Unity標準の取り込み画面で取り込みを実行すると、商品との照合が始まります。Unityの「Import Package」からの取り込みにも対応します。

データの扱い

BLMのローカルDBを読み取り専用で参照します。商品画像はDBに記録されたURLから取得し、Unityタグとアセットの対応表は別ファイルへ保存します。BLMの手動リストとタグは表示・検索でき、Unityタグを追加できます。スマートリストとBLMへの書き戻しは現在未対応です。

Unity 2022.3.22f1で動作確認済みです。Unity 6は未検証です。

BOOTH Library Manager・BOOTHの非公式連携ツールです。

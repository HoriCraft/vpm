Asset Catalog

BOOTH Library Managerと連携する非公式のUnity Editor拡張です。商品画像、タグ、商品ページ、取り込んだアセットをつなぎます。

0.3.0-preview.5 · Windows · Unity 2022.3 · MIT
VCC / ALCOM に追加 ZIPをダウンロード

使い始める

  1. VCC / ALCOMにリポジトリを追加し、先行版パッケージの表示を有効にします。
  2. プロジェクトに HoriCraft Asset Catalog を追加します。
  3. Unityの HoriCraft → Asset Catalog を開きます。
リポジトリURLを手動で追加する

https://horicraft.github.io/vpm/booth-library-unity/index.json

BOOTH Library Managerのデータが見つからないとき

Asset Catalog上部の「BOOTH Library Managerのデータ」を開き、「標準の場所を使う」を押します。手動で選ぶファイルは、BOOTH Library Managerの管理ファイル data.db です。

標準の場所: %APPDATA%\pm.booth.library-manager\data.db

「場所をコピー」でパスをコピーし、「data.db を選ぶ…」のファイル名欄へ貼り付けても開けます。BOOTH Library Managerをまだ使っていない場合は、一度起動して商品を登録してください。DBは読み取り専用で参照します。

ZIPから導入する

ZIPを展開し、中身をプロジェクトの Packages/com.horicraft.booth-library-unity/ に置きます。package.json がこのフォルダーの直下にある状態にしてください。

パッケージを取り込む

商品詳細の「エクスプローラーで開く」で商品フォルダーの中身を直接開き、目的の .unitypackage をダブルクリックします。Unity標準の取り込み画面で取り込みを実行すると、商品を照合し、一つに確定したらアセットを紐づけ、商品画像もAssetsへ自動保存します。Unityの「Import Package」からの取り込みにも対応します。

探す・開く

「フィルタ」でカテゴリ・サブカテゴリ・年齢制限・タグを選べます。ショップ・リスト・プロジェクトへの登録状態も組み合わせられます。タグは「すべて含む／いずれかを含む」を切り替えられます。「Assetsで開く」で紐づいた商品フォルダーをUnityのProject欄に表示します。

すでに導入済みの商品は、Projectでフォルダーを選び「選択フォルダーをこの商品に登録」を押します。商品画像も保存します。画像保存に失敗しても紐づけは維持し、再試行できます。既存の画像は上書きしません。

データの扱い

BOOTH Library ManagerのローカルDBを読み取り専用で参照します。商品画像はDBに記録されたURLから取得し、Unityタグとアセットの対応表は別ファイルへ保存します。BOOTH Library Managerの手動リストとタグは表示・検索でき、Unityタグを追加できます。スマートリストとBOOTH Library Managerへの書き戻しは現在未対応です。

Unity 2022.3.22f1で動作確認済みです。Unity 6は未検証です。

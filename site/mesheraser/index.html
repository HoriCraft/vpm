一覧に自分のシーン・生成物・他製品が含まれる場合は適用を中止してください。旧本体を改変した場合、GUIDが変わった場合、新旧が混在する場合は自動で整理できないことがあります。すべての過去版や改変済みプロジェクトの移行を保証するものではありません。

うまくいかなかったとき

問題が出たコピーはそのまま保管し、移行前のバックアッププロジェクトをVCC／ALCOMに登録して開いてください。元のバックアップへ移行後のファイルを上書きしないでください。パッケージの削除・再追加だけでは、旧Assets本体や保存内容まで元に戻るとは限りません。

解除キーや購入ファイルでの認証は、製品版機能を有効化する別の操作です。認証だけではプロジェクト内の旧本体は移行されません。

Adding a migration-capable MeshEraser version in VCC / ALCOM identifies the old program files and replaces them with the VPM edition. No separate migration EXE or commands are required.

  1. Save your work and close Unity. Back up the entire project. Keep the backup untouched and migrate a separate copy.
  2. Add the MeshEraser repository to VCC / ALCOM and open Manage Project for the copy.
  3. Select a migration-capable MeshEraser version. Check that the removal list contains only old MeshEraser program files, then apply the changes.
  4. Open Unity and the saved scene. Check painted regions, settings, references and any menus or linked behavior you use.
  5. If everything is correct, save, restart Unity and confirm the same state is retained.

If files are listed for removal as legacy assets

This is part of replacing the UnityPackage edition with VPM. Old program files are removed to prevent both versions from loading together.

Only identifiable old program files are migration targets. Paint data, settings, generated assets and saved scenes are not removal targets. Do not delete the entire MeshEraser or parent HoriCraft folder.

Keep the affected copy for investigation. Register and open the pre-migration backup project in VCC / ALCOM. Do not overwrite the original backup with migrated files. Removing and reinstalling a package alone may not restore the old Assets installation or saved data.

Activation with an unlock key or purchased file is a separate step that enables full-version features. Activation alone does not migrate the old installation in your project.

1 このツールについて

MeshEraser（メッシュイレイサー）は、服からハミ出た素体などを、SceneView上でなぞるだけで消せる Unity エディタ拡張です。Blenderを開く必要はありません。

できること

なぞるだけでメッシュを削除
その場で消えるプレビュー
完全非破壊・いつでも復元
ポリゴン数の削減（軽量化）
メニューでON/OFF（トグル）
服連動（脱ぐメニューが1つで）
左右対称に消すXミラー
消す深さの調整（消し残し対策）
日本語・英語・中国語・韓国語UI

できないこと・注意

  • テクスチャを透過して隠す方式ではなく、ジオメトリ（ポリゴン）単位の削除です
  • 対象は VRC Avatar Descriptor が付いたアバターのみです（削除がアバターのビルド時に適用されるため）
  • 「メニューでON/OFF」の利用には Modular Avatar（無料）が必要です

いちばん大事な仕組み

🛡️

3 使い方（3ステップ）

ウィンドウ上部のタブは ① 選ぶ → ② 塗る → ③ 仕上げ ｜ メニュー ｜ 作成済み の5つです。 基本は①→②→③の順に進みます。タブはクリックでいつでも行き来できます。

  • メニュータブ … 作ったトグルの一覧と編集（→ 5-4）
  • 作成済みタブ … 消し範囲の一覧・削除。件数がタブに表示されます（→ 8章）

3-1. ① 選ぶ

  1. 1
    シーンのアバターが自動検出されます（複数いる場合はドロップダウンで選択）。 Hierarchy にアバターが多いときは、「アバターをここへドロップ」の欄にアバター（またはその中のメッシュ）をドラッグ＆ドロップしても選べます。 メッシュを落とした場合は、シーン上でクリックしたのと同じ扱いで「② 塗る」へ進みます。
  2. 2
    SceneView上で、消したいメッシュ（素体など）にマウスを乗せる 候補が蛍光色に光ります。ウィンドウ内の一覧の行にマウスを乗せても同じように光ります。
  3. 3
    クリックで確定。自動で「② 塗る」に進みます
💡
EditorOnlyタグのメッシュ・アバターは一覧に出ません。 EditorOnlyはアップロード時にVRCSDKが削除する目印なので、消す対象になりません。 隠した件数は一覧の下に表示されます。バックアップ複製などをタグで除外している場合の仕様です。
💡
Inspector から始めることもできます。 メッシュのオブジェクトに Add Component で HoriCraft/MeshEraser を付けると、Inspector に消し範囲の要約と ［このメッシュを編集］ボタンが出ます。押すと、そのメッシュを選んだ状態で MeshEraser ウィンドウが開きます。

3-2. ② 塗る

  1. 1
    消したい部分を左ドラッグでこする こすった部分がその場で消えます。
  2. 2
    消しすぎたら「復元」に切り替えてこすり直す Ctrl+Z でも1操作ずつ戻せます。（→ 消しすぎたときは）
  3. 3
    どこまで消したか確かめたいときは「消した色:」で色を選ぶ 消した部分が半透明の色でその場に再表示されます。消し過ぎた所を「復元」でなぞって戻す作業がしやすくなります。 SceneView 上で C キーを押しても切り替えられます（表示だけの設定で、③へ進むと自動で消えた姿に戻ります）。
  4. 4
    できたら 次へ（③ 仕上げ） を押します
💡
カメラ操作（右ドラッグ回転・中ドラッグ移動・ホイールズーム）はUnity標準のままです。 ツールに奪われることはありません。Ctrl+ホイール＝ブラシサイズ、 Shift+ホイール＝消す深さ＋（表面・露出だけモード時）だけが追加されています。

3-3. ③ 仕上げ

  1. 1
    消し方をカードで選ぶ。「完全に削除」（ポリゴンが減って軽量化）か「メニューでON/OFF」（トグル。5章）。選ぶまで完了は押せません
  2. 2
    （トグルのとき）メニュー名・状態表・服連動を設定。初期設定のままでもOKです。既に使われている名前を付けると、完了時に「名前(1)」のように自動で連番が付きます
  3. 3
    完了（この消し範囲を確定） を押す。結果画面から「別の場所を塗る」「作成済みタブへ」「Playモードで確認」へ進めます
  4. 4
    いつも通りアップロードするだけ 完了後にもう一度塗ると、新しい消し範囲として追加されます（併用のやり方）。
⚠️
トグルの動作確認は Gesture Manager か VRChat実機で。 Unityの素のPlayモードではアバターのメニュー（FXアニメーター）が動かないため、トグルを押しても見た目が変わりません。 これはVRChatアバターの仕様で、MeshEraserの不具合ではありません。

9 よくある質問

トグルを押しても、Playモードで何も起きない

Unityの素のPlayモードでは、アバターのメニュー（FXアニメーター）は動きません。VRChatアバター共通の仕様です。

  1. Gesture Manager（無料）を入れてPlayすると、ゲーム内と同じメニューを操作できます
  2. もちろんVRChat実機へのアップロードでも確認できます
消したのにメッシュが残って見える

別のメッシュが同じ場所に重なっているサインです。衣装に素体パーツが含まれているのが典型例です。

  1. 「② 塗る」の対象以外を隠すをONにすると、対象だけの表示で本当に消えているか確認できます
  2. 残っている方のメッシュを「① 選ぶ」で対象にして、同じように消してください

また、Shape Changer入りの衣装ではプレビューの重なりで二重に見えることがあります （→ 7章のヒント。アップロード結果は正常です）。

表面・露出だけモードで、裏側まで消えてしまう

「消す深さ＋」が部位の厚みを超えています。手首・指など細い場所では深さを下げてください（0で従来どおり表面だけになります）。

一覧に出てこないメッシュ・アバターがある

EditorOnlyタグが付いていないか確認してください（親オブジェクトに付いている場合も対象外になります）。 EditorOnlyはアップロードに含まれないため、消す対象からも除外しています。一覧の下に「表示していません」の件数が出ます。

「頂点数が一致しません」と出た

塗った後に、そのメッシュがBlender等で再編集されています。頂点の対応が崩れているため、古い消し範囲は使えません。

表示されるボタンから消し範囲を削除して、塗り直してください。 事故防止のため、古いデータがアップロードに使われることはありません（自動でスキップされます）。

メッシュが消えたまま戻らない

MeshEraserの消し範囲が設定されていて、「ツールを閉じても消した後の姿で表示」（初期値ON）が効いている状態です。メッシュ本体は無事です。

  1. 元に戻したい → 作成済みタブでその消し範囲を［削除］
  2. 表示だけ元に戻したい → 「② 塗る」の表示設定で「ツールを閉じても〜」をOFF
トグルにしたのにメニューが出ない
  1. Modular Avatar がプロジェクトに入っているか確認してください（トグルの生成に必要です）
  2. Playモードでメニューを操作するには Gesture Manager 等が必要です
  3. ③に「メニュー部品が見つかりません」と出ている場合は、シーンの部品が削除されています。表示されるボタンで作り直せます
服連動を設定したら、ゲーム内で服が消えていた

状態表の★（ゲーム開始時）が「メニューOFF」列にあります。OFF列は「素体が表示＝服は非表示」の状態です。 状態表で「★メニューON」の列名をクリックして★を移すと、服を着た状態で始まります。

「NDMFが見つかりません」と表示された

削除の適用に使っている無料の基盤「NDMF」がプロジェクトに入っていません （Modular Avatar か Avatar Optimizer を使っているプロジェクトでは表示されません）。

  1. https://vpm.nadena.dev/ を開き「Add to VCC」を押してリポジトリを登録
  2. VCC / ALCOM の Manage Project から「NDMF」を追加（Modular Avatarを入れれば一緒に入ります）
アバターが見つからないと言われる

アバターのルートに VRC Avatar Descriptor が付いているか確認してください。 削除はアバターのビルド時に適用されるため、Descriptorの無いオブジェクトは対象にできません。 EditorOnlyタグが付いている場合も一覧から除外されます。

ポリゴン数は本当に減りますか？

「完全に削除」を選んだ部分は減ります。アップロード時に三角形と未使用頂点を物理的に除去するため、 VRChatのパフォーマンスランクのポリゴン数にも反映されます。

シェイプキー（表情）・ボーンウェイト・UV・頂点カラーは保持されます。 「メニューでON/OFF」はパーツを分けるだけなのでポリゴンは減りません。

塗り中の見た目と、アップロード後の結果は同じ？

同じです。プレビューの削除判定はビルド時とまったく同じ （三角形の3つの頂点をすべて消したとき、その三角形が削除される）です。

例外は「丸ごと消す」でトグルにした場合で、エディタでは見た目を変えず、Play/アップロード後にだけ消えた状態になります（読み込み時のチラつき防止のための仕様です）。

アバターを壊してしまわないか不安

本ツールは元のメッシュ・FBX・Prefabを一切書き換えません。 保存されるのはメッシュに付く小さなコンポーネント（消す場所の情報）と、トグルの場合のメニュー部品だけで、どちらも削除すれば完全に元の状態です。

心配な場合は、作成済みタブの［削除］でいつでも白紙に戻せます。

Quest（Android）向けでも使えますか？

使えます。削除はプラットフォームに依存しないため、PC・Quest どちらのビルドにも同じように適用されます。 トグルはパーツ分のメッシュ数が増える点にだけご注意ください（→ 5-5の注意）。

1 About This Tool

MeshEraser is a Unity editor extension that erases body parts poking through clothes — just by rubbing them in the Scene view. No Blender required.

What it can do

Erase meshes just by rubbing
Instant erase preview
Non-destructive, always restorable
Polygon reduction (optimization)
Menu ON/OFF toggles
Outfit link (one "undress" menu)
Symmetric erasing (X mirror)
Extra depth (catches leftovers)
Japanese / English / Chinese / Korean UI

What it cannot do / notes

  • This is geometry (polygon) level deletion, not hiding via transparent textures
  • Targets must be avatars with a VRC Avatar Descriptor (deletion is applied during the avatar build)
  • "Menu ON/OFF" requires Modular Avatar (free)

The most important mechanism

🛡️
Your original meshes, FBX and prefabs are never modified The tool only stores "which vertices to erase" in a small component on the mesh. Actual deletion happens at upload (build) time, applied only to the duplicate mesh created by NDMF. Leave Play mode and everything is back; delete the erase region and it is as if nothing happened.
⚠️
About quality Undiscovered bugs may remain. If you find unexpected behavior, please let us know through BOOTH messages.

3 How to Use (3 Steps)

The window has five tabs: ① Select → ② Paint → ③ Finish | Menu | Created. The basic flow is ① → ② → ③. You can switch tabs freely at any time.

  • Menu tab … list and edit the toggles you created (→ 5-4)
  • Created tab … list and delete erase regions. The count is shown on the tab (→ Section 8)

3-1. ① Select

  1. 1
    Avatars in the scene are detected automatically (choose from the dropdown if there are several). If the Hierarchy holds many avatars, you can also drag & drop the avatar (or a mesh inside it) onto the "Drop an avatar here" field. Dropping a mesh is treated like clicking it in the scene and takes you to "② Paint".
  2. 2
    Hover over the mesh you want to erase (e.g. the body) in the Scene view Candidates light up in a highlight color. Hovering rows in the window list highlights them too.
  3. 3
    Click to confirm. You move to "② Paint" automatically
💡
Meshes and avatars tagged EditorOnly are not listed. EditorOnly marks objects that VRCSDK strips at upload, so there is nothing to erase on them. The number of hidden items is shown below the list. This matters if you keep backup copies excluded via that tag.
💡
You can also start from the Inspector. Add Component → HoriCraft/MeshEraser on the mesh object shows a summary of its erase regions and an [Edit this mesh] button in the Inspector. Pressing it opens the MeshEraser window with that mesh already selected.

3-2. ② Paint

  1. 1
    Rub the area you want to erase with left-drag The rubbed area disappears on the spot.
  2. 2
    Erased too much? Switch to "Restore" and rub it back Ctrl+Z also undoes one operation at a time. (→ If You Erased Too Much)
  3. 3
    To check how far you have erased, choose a color in "Erased color:" Erased parts are re-displayed in place in a translucent color, which makes it easier to rub over-erased spots back with "Restore". Pressing C over the Scene view toggles it too (display only; it turns off automatically when you move to ③).
  4. 4
    When done, press Next (③ Finish)
💡
Camera controls (right-drag orbit, middle-drag pan, wheel zoom) stay standard Unity — the tool never takes them over. Only Ctrl+Wheel (brush size) and Shift+Wheel (extra depth, in Surface / Exposed-only modes) are added.

3-3. ③ Finish

  1. 1
    Choose how to erase on the cards: "Delete completely" (fewer polygons, lighter avatar) or "Menu ON/OFF" (toggle, Section 5). You cannot finish until you choose
  2. 2
    (For toggles) set the menu name, state table and outfit link. Defaults are fine. If the name is already in use, a suffix like "Name(1)" is added automatically on finish
  3. 3
    Press Finish (confirm this erase region). From the result banner you can go to "Paint another area", "Open the Created tab" or "Check in Play mode"
  4. 4
    Upload as usual — that's it Painting again after finishing creates a new, separate erase region (combining).
⚠️
Check toggles with Gesture Manager or in VRChat itself. In plain Unity Play mode the avatar menu (FX animator) does not run, so pressing a toggle changes nothing. This is how VRChat avatars work — it is not a MeshEraser bug.

4 Erase Settings

Listed top to bottom on the "② Paint" screen. The defaults work fine as they are.

4-1. Choosing a Tool

ToolHow to use
Brush (default)Rub with left-drag to erase. Good for fine control. Size via Ctrl+Wheel or the slider
Rectangle / EllipseLeft-drag a region in the Scene view; everything inside is erased the moment you release. Esc during the drag cancels
Erase whole
(select this entire mesh)		Selects the entire mesh as the erase region without painting. For removing or toggling whole hair parts and accessories. "Restore whole" (or Ctrl+Z) undoes it
💡
Touching a triangle erases it. Any triangle the brush or region touches even partially is removed whole, and the one under the cursor always is. A brush smaller than the polygons is fine. To see polygon density, enable "Show wireframe" in the display options.

4-2. Erase Scope & Depth

ModeWhat gets erasedBest for
Through (default)Everything in a cylinder, all the way throughUse this normally. Wipes out the body under the clothes
SurfaceCamera-facing surfaces (including under clothes)Careful erasing of the front side only
Exposed onlyOnly "visible" parts not hidden by clothesRub roughly over the outfit and only the poke-through goes

Extra depth (cm) — Surface / Exposed-only modes

How much deeper than the surface to erase. Increase it to catch leftovers just under the surface, such as hair inside a helmet (brush only; also adjustable with Shift+Wheel).

  • The value is remembered per mode. Defaults: Exposed only = 2 cm / Surface = 0 cm (surface only)
  • On thin parts like wrists and fingers, a depth larger than the part's thickness can reach the back side. Lower the depth for fine areas

4-3. X Mirror (erase symmetrically)

When ON, rubbing one side erases the opposite side symmetrically (works with brush, rectangle and ellipse).

  • The sub-option "hide the mirrored half" hides the side you are not working on so you can focus (display only — data is unaffected)
  • On meshes that are not symmetric, spots with no corresponding vertex are left as they are

5 Menu ON/OFF (Toggles) & Outfit Link

Choosing Menu ON/OFF in "③ Finish" lets you show/hide the painted area from the avatar's Expression menu instead of deleting it (requires Modular Avatar, free).

5-1. How it works (no mesh deformation)

On finish, a menu object (with a set of Modular Avatar components) is generated directly under the avatar. The object's name is the menu name — renaming it in the Hierarchy renames the menu.

At build time the painted area is split into a separate part, and the toggle simply shows/hides that part. Unlike blendshape-based approaches, the mesh is never deformed, so edges cannot get stretched or broken. Polygons remain, so this does not make the avatar lighter (use "Delete completely" where you want optimization).

💡
For Modular Avatar users: only plain MA components are generated (MergeAnimator / Parameters / MenuItem / MenuInstaller). You can edit them directly in the Inspector or with menu-editing tools; changes are reflected back into MeshEraser's UI (two-way).

5-2. Reading the state table (★ = at game start)

The "Targets (★ = at game start)" table in ③ and the Menu tab shows what is visible or hidden for each of Menu ON and Menu OFF.

ActionMeaning
Click a column header (★Menu ON / Menu OFF)The ★ (state at game start) moves to that column. Default is ON = the painted area starts hidden
Click an outfit rowFlips that outfit's visibility in that column (adjust the link direction right on the table)
The "painted area" rowHidden on ON, shown on OFF (fixed — it is what this toggle controls)
💡
Clicking the ★ column again re-syncs the settings. If another tool left part visibility out of sync, pressing ★ again repairs it.

5-3. Toggle the outfit too (optional)

Register an outfit and it switches together: "ON = outfit shown + body erased / OFF = outfit hidden + body restored". A complete "undress" menu from a single toggle.

  • Register by clicking the outfit in the Scene view ("pick in scene") or by dragging it into the field
  • [Remove] unregisters it. Flip the link direction by clicking the outfit's row in the state table

5-4. The Menu tab (editing afterwards)

A list of the toggles you created. Click a row or [Edit] to select it and edit below.

💡
To delete a toggle and restore everything: use [Delete] on the "Created" tab. The menu object is removed too, and the avatar returns to exactly how it was.

5-5. Combining with complete deletion

Painting the same mesh again after [Finish] creates a new erase region. Make pass one "Delete completely" and pass two "Menu ON/OFF" to combine both on one mesh. Where the two overlap, complete deletion wins.

⚠️
About Quest and other constrained targets A toggle adds one part (renderer) for switching. Mind this if you are aiming for performance ranks with strict Skinned Mesh limits.

5-6. Linked shape keys (optional)

Along with the toggle's ON/OFF, you can drive shape keys on other meshes between 100 and 0. Useful when an outfit's shape keys (smaller chest, slimmer waist, etc.) adjust the body shape and should switch together with the outfit.

  • In ③ Finish (or the Menu tab), in the "Shape keys" part of the "Add to the table above" card under "Toggle clothes and shape keys together (optional)", press [+ Add shape key] and choose the mesh and the shape key name
  • Default is "100 when the toggle is ON, 0 when OFF". Click the shape key's row in the state table to swap 100/0
  • [Remove] unregisters it. Shape keys on the target mesh itself cannot be linked (it is the mesh being erased)

9 FAQ

Nothing happens when I press the toggle in Play mode

In plain Unity Play mode, the avatar menu (FX animator) does not run. This applies to all VRChat avatars.

  1. Install Gesture Manager (free) and enter Play mode to operate the same menu as in-game
  2. Uploading to VRChat itself of course works too
I erased it, but a mesh still shows there

A sign that another mesh overlaps the same spot — outfits bundling their own body parts are the classic case.

  1. Turn ON Hide others in "② Paint" to check, with only the target visible, whether it is really erased
  2. Select the remaining mesh in "① Select" and erase it the same way

With Shape Changer outfits, overlapping previews can also make the body look doubled (→ hint in Section 7; the uploaded result is correct).

Surface / Exposed-only mode erased through to the back side

The "extra depth" exceeds the part's thickness. Lower the depth on thin areas like wrists and fingers (0 = surface only, as before).

Some meshes / avatars do not appear in the list

Check for the EditorOnly tag (a parent object having it also excludes the children). EditorOnly objects are not included in uploads, so they are excluded from erasing too. A note below the list shows how many were hidden.

"Vertex count mismatch" appeared

The mesh was re-edited in Blender etc. after you painted. The vertex mapping is broken, so the old erase region cannot be used.

Delete the erase region via the button shown and repaint. To prevent accidents, stale data is never used for uploads (it is skipped automatically).

A mesh stays erased and will not come back

An erase region is set and "Keep showing the erased look after closing" (default ON) is in effect. The mesh itself is fine.

  1. To restore it → [Delete] that erase region on the Created tab
  2. To restore only the display → turn OFF "Keep showing…" in ②'s display options
I made a toggle but no menu appears
  1. Check that Modular Avatar is in the project (required to generate toggles)
  2. Operating the menu in Play mode requires Gesture Manager or similar
  3. If ③ says "menu object missing", it was deleted from the scene — the button shown there recreates it
I set the outfit link, and in-game the outfit was gone

The ★ (game start) in the state table is on the "Menu OFF" column. The OFF column means "body shown = outfit hidden". Click the "★Menu ON" column header in the state table to move the ★ there, and you start dressed.

"NDMF not found" is displayed

The free framework "NDMF", used to apply the deletion, is not in the project (this message never appears in projects using Modular Avatar or Avatar Optimizer).

  1. Open https://vpm.nadena.dev/ and press "Add to VCC" to register the repository
  2. Add "NDMF" from Manage Project in VCC / ALCOM (installing Modular Avatar brings it in too)
It says no avatar was found

Check that the avatar root has a VRC Avatar Descriptor. Deletion is applied during the avatar build, so objects without a Descriptor cannot be targeted. Avatars tagged EditorOnly are also excluded from the list.

Does the polygon count really go down?

Yes, for areas set to "Delete completely". Triangles and unused vertices are physically removed at upload, so it counts toward VRChat's performance-rank polygon count.

Blendshapes (facial expressions), bone weights, UVs and vertex colors are preserved. "Menu ON/OFF" only splits parts, so it does not reduce polygons.

Is the painted preview the same as the uploaded result?

Yes. The preview uses exactly the same deletion rule as the build (a triangle is removed when all three of its vertices are erased).

The one exception is whole-mesh toggles made with "Erase whole": the editor look stays unchanged, and the mesh appears erased only in Play mode / after upload (by design, to avoid flicker on load).

I'm worried about breaking my avatar

This tool never modifies your original meshes, FBX or prefabs. All it stores is a small component on the mesh (where to erase) plus, for toggles, the menu object — delete them and everything is exactly as before.

If in doubt, [Delete] on the Created tab returns you to a clean slate at any time.

Can I use it for Quest (Android) avatars?

Yes. Deletion is platform-independent and applies equally to PC and Quest builds. Just note that toggles add one extra mesh for the split part (→ note in 5-5).

  4. 4

  5. 5
    정식판: 지우는 방식을 골라 「완료」→ 평소대로 업로드 체험판에서는 이 단계를 사용할 수 없습니다. 10장의 절차로 해제하면 이미 칠한 지우기 범위를 그대로 사용할 수 있습니다.
    카드에서 '완전 삭제'(경량화) 또는 '메뉴로 ON/OFF'(토글)를 골라 완료. 삭제는 업로드 시 자동 적용됩니다
💡 실수해도 괜찮습니다. 원본 메시·FBX·Prefab에는 일절 손대지 않는 완전 비파괴 설계입니다. 언제든 Ctrl+Z로 되돌릴 수 있고, '생성됨' 탭에서 지우기 범위를 삭제하면 완전히 원래대로 돌아갑니다.
⚠️ 토글 동작 확인은 Gesture Manager(무료) 또는 VRChat 실기에서. Unity 순정 Play 모드에서는 아바타 메뉴가 동작하지 않습니다(모든 VRChat 아바타 공통 사양).

3 사용법（3단계）

창 상단의 탭은 ① 선택 → ② 칠하기 → ③ 마무리 ｜ 메뉴 ｜ 생성됨의 5개입니다. 기본은 ①→②→③ 순서로 진행하며, 탭은 언제든 클릭으로 오갈 수 있습니다.

  • 메뉴 탭 … 만든 토글의 목록과 편집(→ 5-4)
  • 생성됨 탭 … 지우기 범위의 목록·삭제. 개수가 탭에 표시됩니다(→ 8장)

3-1. ① 선택

  1. 1
    씬의 아바타가 자동으로 감지됩니다(여럿일 때는 드롭다운에서 선택). Hierarchy에 아바타가 많을 때는 '아바타를 여기에 드롭' 칸에 아바타(또는 그 안의 메시)를 드래그 앤 드롭해서 고를 수도 있습니다. 메시를 드롭하면 씬에서 클릭한 것과 같은 취급으로 '② 칠하기'로 넘어갑니다.
  2. 2
    SceneView에서 지우고 싶은 메시(몸 등)에 마우스를 올린다 후보가 형광색으로 빛납니다. 창 안 목록의 행에 마우스를 올려도 똑같이 빛납니다.
  3. 3
    클릭으로 확정. 자동으로 '② 칠하기'로 넘어갑니다
💡
EditorOnly 태그가 붙은 메시·아바타는 목록에 나오지 않습니다. EditorOnly는 업로드 시 VRCSDK가 삭제하는 표시이므로 지울 의미가 없기 때문입니다. 숨긴 개수는 목록 아래에 표시됩니다. 백업 복제본을 태그로 제외하는 경우에 해당합니다.
💡
Inspector에서 시작할 수도 있습니다. 메시 오브젝트에 Add Component → HoriCraft/MeshEraser를 붙이면 Inspector에 지우기 범위 요약과 [이 메시 편집] 버튼이 나타납니다. 누르면 그 메시를 선택한 상태로 MeshEraser 창이 열립니다.

3-2. ② 칠하기

  1. 1
    지우고 싶은 부분을 왼쪽 드래그로 문지른다 문지른 부분이 그 자리에서 사라집니다.
  2. 2
    너무 지웠으면 '복원'으로 전환해 다시 문지른다 Ctrl+Z로도 한 번에 한 단계씩 되돌릴 수 있습니다.(→ 너무 지웠을 때)
  3. 3
    어디까지 지웠는지 확인하려면 '지운 부분 색상:'에서 색을 선택하세요 지운 부분이 반투명 색으로 그 자리에 다시 표시되어, 너무 지운 곳을 '복원'으로 문질러 되돌리기 쉬워집니다. SceneView에서 C 키를 눌러도 전환됩니다(표시만의 설정으로, ③으로 넘어가면 자동으로 지운 모습으로 돌아갑니다).
  4. 4
    다 되면 다음(③ 마무리)을 누릅니다
💡
카메라 조작(오른쪽 드래그 회전·가운데 드래그 이동·휠 줌)은 Unity 표준 그대로입니다. 도구가 빼앗지 않습니다. 추가된 것은 Ctrl+휠(브러시 크기)과 Shift+휠(지우기 깊이＋, 표면·노출만 모드)뿐입니다.

3-3. ③ 마무리

  1. 1
    지우는 방식을 카드에서 선택: '완전 삭제'(폴리곤이 줄어 경량화) 또는 '메뉴로 ON/OFF'(토글, 5장). 고를 때까지 완료를 누를 수 없습니다
  2. 2
    (토글일 때) 메뉴 이름·상태표·옷 연동을 설정. 기본값 그대로도 OK. 이미 사용 중인 이름을 붙이면 완료 시 '이름(1)'처럼 자동으로 번호가 붙습니다
  3. 3
    완료(이 지우기 범위를 확정)를 누른다. 결과 화면에서 '다른 곳 칠하기', '생성됨 탭 열기', 'Play 모드에서 확인'으로 이동할 수 있습니다
  4. 4
    평소대로 업로드하면 끝 완료 후 다시 칠하면 새로운 지우기 범위로 추가됩니다(병용 방법).
⚠️
토글의 동작 확인은 Gesture Manager 또는 VRChat 실기에서. Unity의 순정 Play 모드에서는 아바타 메뉴(FX 애니메이터)가 동작하지 않아 토글을 눌러도 겉모습이 바뀌지 않습니다. 이는 VRChat 아바타의 공통 사양이며 MeshEraser의 버그가 아닙니다.

4 지우기 설정

'② 칠하기' 화면에 위에서부터 순서대로 나열되어 있습니다. 기본 설정 그대로도 문제없이 쓸 수 있습니다.

4-1. 도구 선택

도구사용법
브러시(기본값)왼쪽 드래그로 문질러 지웁니다. 세밀한 조정용. 크기는 Ctrl+휠 또는 슬라이더로
사각형 / 원형SceneView에서 왼쪽 드래그로 범위를 그리면 놓는 순간 범위 안이 한꺼번에 지워집니다. 드래그 중 Esc로 취소
통째로 지우기
(이 메시 전체를 선택)		칠하지 않고 메시 전체를 지우기 범위로 만듭니다. 머리 파츠나 아이템을 통째로 지우거나 ON/OFF하고 싶을 때. '통째로 되돌리기'(또는 Ctrl+Z)로 해제
💡
일부라도 닿으면 지워집니다. 브러시나 범위가 조금이라도 닿은 삼각형은 통째로 지워지고, 커서 바로 아래는 반드시 지워집니다. 브러시가 폴리곤보다 작아도 괜찮습니다. 폴리곤 밀도를 보고 싶으면 표시 설정의 '폴리곤 선 표시'를 켜세요.

4-2. 지우기 범위와 깊이

모드지워지는 범위알맞은 상황
관통(기본값)브러시 안쪽 끝까지 원통형으로 전부평소엔 이것. 옷 아래의 몸을 통째로 지운다
표면카메라를 향한 면(옷 아래 포함)앞면만 신중하게 지우고 싶을 때
노출만옷 등에 가려지지 않은 '보이는 부분'만옷 위로 대충 문질러도 삐져나온 부분만 지워진다

지우기 깊이＋(cm) ── 표면·노출만 모드 전용

표면에서 더 안쪽으로 지우는 깊이입니다. 헬멧 속 머리카락처럼 표면 바로 아래에 남는 잔여물을 함께 지우고 싶을 때 늘립니다(브러시 전용, Shift+휠로도 조절 가능).

  • 값은 모드별로 따로 기억됩니다. 기본값: 노출만＝2cm／표면＝0cm(표면만)
  • 손목·손가락처럼 얇은 부위에서는 깊이가 두께를 넘으면 뒷면까지 지워질 수 있습니다. 세밀한 부위에서는 깊이를 낮춰 주세요

4-3. X미러(좌우 대칭으로 지우기)

켜면 한쪽만 문질러도 반대쪽도 대칭으로 지워집니다(브러시·사각형·원형 모두에 적용).

  • 하위 옵션 '미러 쪽 절반을 숨겨 표시'로 작업하지 않는 쪽을 숨기고 한쪽에 집중할 수 있습니다(표시만의 변경, 데이터에는 영향 없음)
  • 좌우 형태가 다른 메시에서는 대응하는 정점이 없는 부분은 그대로 남습니다

5 메뉴 ON/OFF(토글)와 옷 연동

'③ 마무리'에서 메뉴로 ON/OFF를 고르면, 삭제하는 대신 아바타의 Expression 메뉴에서 칠한 부분의 표시를 전환할 수 있습니다(Modular Avatar(무료) 필요).

5-1. 동작 원리(메시는 변형되지 않습니다)

완료하면 아바타 바로 아래에 메뉴 부품(Modular Avatar 컴포넌트 세트가 붙은 오브젝트)이 생성됩니다. 오브젝트 이름＝메뉴 이름으로, Hierarchy에서 이름을 바꾸면 메뉴 이름도 바뀝니다.

칠한 부분은 빌드 시 별도 파츠로 분리되고, 토글은 그 파츠의 표시를 전환할 뿐입니다. 셰이프키 방식과 달리 메시를 변형시키지 않으므로 경계가 늘어나는 붕괴가 일어나지 않습니다. 폴리곤은 남으므로 경량화는 되지 않습니다(경량화하고 싶은 곳은 '완전 삭제'를 쓰세요).

💡
Modular Avatar에 익숙한 분께: 생성되는 것은 순정 MA 컴포넌트 (MergeAnimator／Parameters／MenuItem／MenuInstaller)뿐입니다. Inspector나 메뉴 편집 도구로 직접 편집할 수 있고, 변경은 MeshEraser UI에도 반영됩니다(양방향).

5-2. 상태표 읽는 법(★＝게임 시작 시)

③과 메뉴 탭에 나오는 '대상(★=게임 시작 시)' 표에서 메뉴 ON/OFF 각각일 때 무엇이 표시·숨김되는지 한눈에 볼 수 있습니다.

열 이름(★메뉴 ON / 메뉴 OFF) 클릭★(게임 시작 시 상태)가 그 열로 이동합니다. 기본값은 ON＝칠한 부분이 지워진 상태로 시작
옷 행 클릭그 옷의 표시/숨김이 그 열에서 반전됩니다(연동 방향을 표에서 바로 조정)
'칠한 부분' 행ON에서 숨김·OFF에서 표시(이 토글의 기준이므로 고정)
💡

5-3. 옷도 함께 전환(선택)

옷을 등록하면 "ON＝옷 표시＋몸 지움／OFF＝옷 숨김＋몸 복원"으로 연동됩니다. '옷 벗기 메뉴'가 토글 하나로 만들어집니다.

  • 등록은 '씬에서 선택'으로 SceneView의 옷을 클릭하거나, 칸에 드래그
  • ［빼기］로 해제. 연동 방향은 상태표에서 옷 행을 클릭해 반전할 수 있습니다

5-4. 메뉴 탭(만든 뒤의 편집)

만든 토글의 목록입니다. 행 클릭 또는 ［편집］으로 선택하면 아래에서 편집할 수 있습니다.

항목설명
메뉴 이름게임 내 메뉴에 표시되는 이름(씬 오브젝트 이름과 동일)
상태표·옷 연동③과 같은 조작으로 언제든 변경 가능
범위 편집②로 이동해 이 메시의 지우기 범위를 더 칠하거나 다시 칠할 수 있습니다
합치기지금 편집 중인 토글을 선택한 상대 버튼 안에 합칩니다(여러 지우기 범위를 버튼 1개로 전환)
별도 버튼으로 분리합쳐진 토글에서 이 메시만 독립 버튼으로 되돌립니다('합치기'의 반대)
Play 모드에서 확인Play 모드로 들어갑니다(메뉴 조작에는 Gesture Manager 필요)
💡
토글을 삭제하고 원래대로 되돌리려면: '생성됨' 탭의 ［삭제］를 사용하세요. 메뉴 부품도 함께 사라지고 아바타는 완전히 원래대로 돌아갑니다.

5-5. 완전 삭제와 병용

［완료］ 후 같은 메시를 다시 칠하면 새 지우기 범위로 추가됩니다. 1회차를 '완전 삭제', 2회차를 '메뉴로 ON/OFF'로 하면 같은 메시에서 병용할 수 있습니다. 같은 곳을 양쪽으로 칠한 경우 완전 삭제가 우선됩니다.

⚠️
Quest 등 제한이 엄격한 환경에 대하여 토글은 전환용 파츠(렌더러)가 1개 늘어납니다. Skinned Mesh 수 상한이 엄격한 퍼포먼스 랭크를 노리는 경우 주의하세요.

5-6. 셰이프 키 연동(선택)

토글의 ON/OFF에 맞춰 다른 메시의 셰이프 키를 100 ⇔ 0으로 움직일 수 있습니다. 옷의 셰이프 키(가슴 축소, 허리 슬림 등)로 체형을 맞추고 있어서 옷 착탈과 함께 전환하고 싶을 때 씁니다.

  • ③ 마무리(또는 메뉴 탭)의 '옷·셰이프 키도 함께 전환(선택)'에 있는 '↑ 표에 추가할 항목' 카드의 '셰이프 키' 칸에서 [＋ 셰이프 키 추가] → 메시와 셰이프 키 이름을 고릅니다
  • 기본은 '토글 ON일 때 100, OFF일 때 0'. 상태표의 셰이프 키 행을 클릭하면 100/0이 바뀝니다
  • [빼기]로 해제. 대상 메시 자신의 셰이프 키는 연동할 수 없습니다(지우는 대상이므로)

6 너무 지웠을 때

'② 칠하기' 화면의 '너무 지웠다면:' 그룹에 모여 있습니다.

버튼기능
복원왼쪽 드래그의 동작을 전환합니다. 지운 부분을 문지르면 돌아옵니다
직전 취소(Ctrl+Z)직전 1회 조작을 취소합니다. Ctrl+Y로 다시 실행

경계 다듬기지운 가장자리의 들쭉날쭉함을 자동으로 정리합니다. 반복해서 누르면 더 매끄러워집니다

💡

7 표시 옵션

창을 닫지 않고 결과 확인하기 SceneView 옆에 창을 도킹하고 ②에서 H를 누르면 대상 하이라이트, C를 누르면 지운 부분 색상의 표시/숨김이 전환됩니다. 키는 SceneView와 MeshEraser 창 중 어느 쪽을 선택해도 작동합니다(메뉴 이름 등 문자 입력 중 제외). 색 설정이나 지우기 데이터는 바뀌지 않습니다. 같은 씬이 열린 동안에는 창을 다시 열면 이전 대상, 지우기 범위와 ② 또는 ③부터 이어집니다. [처음부터 선택]으로 기억을 지울 수 있고 Unity를 종료해도 지워집니다. 대상이나 지우기 범위가 바뀌었다면 ①부터 다시 선택합니다.

'② 칠하기' 화면의 '표시:' 그룹입니다. 지우기 조작에는 영향 없는, 겉모습만의 설정입니다.

항목설명
하이라이트 색상편집 중인 대상 메시에 겹쳐 표시할 색입니다. 프리셋이나 사용자 지정 색을 선택할 수 있습니다. 이 줄의 OFF는 대상 하이라이트만 숨깁니다. H 키로도 전환할 수 있습니다(키 안내는 줄 오른쪽 끝)
지운 부분 색상색을 선택하면 지운 부분이 반투명하게 표시됩니다. 기본값은 연한 하늘색이며, 연한 하늘색·청회색·흰색·연보라색 프리셋이나 사용자 지정 색을 선택할 수 있습니다. 이 줄의 OFF는 지운 부분을 숨깁니다. C 키로도 표시를 전환할 수 있습니다(키 안내는 줄 오른쪽 끝)
대상 외 숨기기옷 등을 일시적으로 숨겨 덜 지운 곳을 확인할 수 있습니다. 씬에 저장되지 않는 안전한 표시 전환입니다
폴리곤 선 표시폴리곤의 변을 검은 선으로 표시합니다. 브러시와 폴리곤의 크기 대비가 보입니다(표시 중엔 조금 무거워짐)
도구를 닫아도 '지운 후의 모습'으로 표시켜면 도구를 닫은 동안에도 씬에서 지워진 채 표시됩니다(기본값 ON. 표시만의 변경으로, 씬에는 아무것도 기록하지 않음). 이 설정은 '생성됨' 탭에도 있습니다. NDMF 1.5 이상에서는 NDMF의 미리보기 기능 위에서 동작하므로, 다른 도구의 미리보기(MA Shape Changer 등)와 같은 표시 위에서 합성되며 NDMF의 미리보기 ON/OFF 메뉴에도 'MeshEraser 지운 후의 모습'으로 나타납니다
💡
MA Shape Changer가 든 의상에서 몸이 이중으로 보일 때: MeshEraser 창이 열려 있는 동안은 다른 도구의 미리보기(분신 표시)를 자동으로 일시정지해 올바른 모습을 보여줍니다. 창을 닫으면 원래 미리보기로 돌아가며, NDMF 1.5 이상이라면 '지운 후의 모습'도 그 위에 합성됩니다(v1.1에서, 닫으면 지운 부분이 되살아나 보이던 문제를 수정). 어느 쪽이든 업로드 결과는 정상입니다.

8 생성됨 탭

아바타 안의 모든 지우기 범위를 메시별로 한눈에 볼 수 있습니다(개수는 탭에 표시). 행에 마우스를 올리면 씬의 해당 메시가 빛납니다.

조작설명
편집그 지우기 범위를 '③ 마무리'에서 열어, 지우는 방식·메뉴 이름·옷 연동을 나중에 변경할 수 있습니다
삭제그 지우기 범위만 삭제합니다(다른 범위와 메시 본체는 그대로). 삭제하면 그 부분은 완전히 원래대로 돌아갑니다
모든 지우기 범위 삭제아바타 안의 지우기 범위를 한꺼번에 삭제합니다(Ctrl+Z로 되돌릴 수 있음)
💡
삭제되는 것은 '지우기 범위(어디를 지울지의 정보)'뿐입니다. 메시 본체가 사라지는 일은 없습니다. 토글의 경우 메뉴 부품도 함께 정리됩니다.

9 자주 묻는 질문

Play 모드에서 토글을 눌러도 아무 일도 일어나지 않는다

Unity의 순정 Play 모드에서는 아바타 메뉴(FX 애니메이터)가 동작하지 않습니다. 모든 VRChat 아바타에 공통입니다.

  1. Gesture Manager(무료)를 설치하고 Play하면 게임 내와 같은 메뉴를 조작할 수 있습니다
  2. 물론 VRChat 실기에 업로드해 확인해도 됩니다
지웠는데 메시가 남아 보인다

다른 메시가 같은 자리에 겹쳐 있다는 신호입니다. 의상에 몸 파츠가 포함된 것이 전형적인 예입니다.

  1. '② 칠하기'의 대상 외 숨기기를 켜면, 대상만 표시된 상태에서 정말 지워졌는지 확인할 수 있습니다
  2. 남아 있는 쪽 메시를 '① 선택'에서 대상으로 잡아 똑같이 지우세요

또한 Shape Changer가 든 의상에서는 미리보기 겹침으로 몸이 이중으로 보일 수 있습니다 (→ 7장의 힌트. 업로드 결과는 정상입니다).

표면·노출만 모드인데 뒷면까지 지워졌다

'지우기 깊이＋'가 부위의 두께를 넘고 있습니다. 손목·손가락처럼 얇은 곳에서는 깊이를 낮춰 주세요(0이면 예전처럼 표면만).

목록에 나오지 않는 메시·아바타가 있다

EditorOnly 태그가 붙어 있지 않은지 확인하세요(부모 오브젝트에 붙어 있어도 제외됩니다). EditorOnly는 업로드에 포함되지 않으므로 지우기 대상에서도 제외합니다. 목록 아래에 숨긴 개수가 표시됩니다.

'정점 수가 일치하지 않습니다'가 나왔다

칠한 뒤에 그 메시가 Blender 등에서 다시 편집되었습니다. 정점 대응이 깨져 있어 예전 지우기 범위는 쓸 수 없습니다.

표시되는 버튼으로 지우기 범위를 삭제하고 다시 칠하세요. 사고 방지를 위해 오래된 데이터가 업로드에 쓰이는 일은 없습니다(자동으로 건너뜁니다).

메시가 지워진 채 돌아오지 않는다

지우기 범위가 설정되어 있고 '도구를 닫아도 지운 후의 모습으로 표시'(기본값 ON)가 작동 중인 상태입니다. 메시 본체는 무사합니다.

  1. 원래대로 되돌리고 싶다 → 생성됨 탭에서 그 지우기 범위를 ［삭제］
  2. 표시만 되돌리고 싶다 → ②의 표시 설정에서 '도구를 닫아도～'를 OFF
토글로 했는데 메뉴가 나오지 않는다
  1. Modular Avatar가 프로젝트에 있는지 확인하세요(토글 생성에 필요)
  2. Play 모드에서 메뉴를 조작하려면 Gesture Manager 등이 필요합니다
  3. ③에 '메뉴 부품을 찾을 수 없습니다'가 표시되면 씬의 부품이 삭제된 것입니다 — 거기 표시되는 버튼으로 다시 만들 수 있습니다
옷 연동을 설정했더니 게임 안에서 옷이 사라져 있었다

상태표의 ★(게임 시작 시)가 '메뉴 OFF' 열에 있습니다. OFF 열은 '몸 표시＝옷 숨김' 상태입니다. 상태표에서 '★메뉴 ON' 열 이름을 클릭해 ★를 옮기면 옷을 입은 상태로 시작합니다.

'NDMF를 찾을 수 없습니다'가 표시됐다

삭제 적용에 쓰는 무료 기반 'NDMF'가 프로젝트에 없습니다 (Modular Avatar나 Avatar Optimizer를 쓰는 프로젝트에서는 표시되지 않습니다).

  1. https://vpm.nadena.dev/를 열어 "Add to VCC"를 눌러 저장소 등록
  2. VCC / ALCOM의 Manage Project에서 "NDMF"를 추가(Modular Avatar를 설치하면 함께 들어옵니다)
아바타를 찾을 수 없다고 나온다

아바타 루트에 VRC Avatar Descriptor가 붙어 있는지 확인하세요. 삭제는 아바타 빌드 시 적용되므로 Descriptor가 없는 오브젝트는 대상이 될 수 없습니다. EditorOnly 태그가 붙은 아바타도 목록에서 제외됩니다.

폴리곤 수가 정말 줄어드나요?

'완전 삭제'를 고른 부분은 줄어듭니다. 업로드 시 삼각형과 미사용 정점을 물리적으로 제거하므로, VRChat 퍼포먼스 랭크의 폴리곤 수에도 반영됩니다.

셰이프키(표정)·본 웨이트·UV·정점 컬러는 유지됩니다. '메뉴로 ON/OFF'는 파츠를 나눌 뿐이라 폴리곤은 줄지 않습니다.

칠할 때의 모습과 업로드 후의 결과는 같은가요?

같습니다. 미리보기의 삭제 판정은 빌드 시와 완전히 동일합니다 (삼각형의 정점 3개가 모두 지워지면 그 삼각형이 삭제됨).

단 하나의 예외는 '통째로 지우기'로 만든 통째 토글로, 에디터에서는 모습이 바뀌지 않고 Play 모드/업로드 후에만 지워진 상태가 됩니다(로드 시 깜빡임 방지를 위한 설계).

아바타를 망가뜨릴까 봐 불안하다

본 도구는 원본 메시·FBX·Prefab을 일절 수정하지 않습니다. 저장되는 것은 메시에 붙는 작은 컴포넌트(지울 위치 정보)와, 토글의 경우 메뉴 부품뿐 — 삭제하면 완전히 원래 상태입니다.

걱정된다면 언제든 생성됨 탭의 ［삭제］로 백지 상태로 돌아갈 수 있습니다.

1 关于本工具

MeshEraser 是一款 Unity 编辑器扩展：只需在 SceneView 中涂抹，就能擦掉从衣服里穿出来的身体等网格。无需打开 Blender。

能做什么

涂一涂就能删除网格
当场可见的擦除预览
完全非破坏、随时恢复
减少多边形数（轻量化）
菜单开关（ON/OFF）
衣服联动（一键“换装”菜单）
左右对称擦除（X镜像）
加深擦除（清理残留）
日语/英语/中文/韩语UI

做不到的事・注意

  • 不是用透明贴图隐藏，而是按几何体（多边形）单位删除
  • 只能作用于带有 VRC Avatar Descriptor 的虚拟形象（因为删除在虚拟形象构建时应用）
  • 使用“菜单开关（ON/OFF）”需要 Modular Avatar（免费）

最重要的机制

🛡️
不会改写原始网格、FBX、Prefab 工具只在网格上的一个小组件里保存“要擦除哪些顶点”的信息。 实际删除发生在上传（构建）时，只作用于 NDMF 生成的复制网格。 退出 Play 模式即恢复原样；删除擦除范围就完全当作没发生过。
⚠️
关于质量 仍可能存在尚未发现的问题。如遇异常行为，请通过 BOOTH 消息告知。

3 使用方法（3步）

窗口上方共有5个标签页：① 选择 → ② 涂抹 → ③ 完成 ｜ 菜单 ｜ 已创建。 基本按①→②→③进行，随时可以点击切换。

  • 菜单标签页 … 已创建开关的列表与编辑（→ 5-4）
  • 已创建标签页 … 擦除范围的列表与删除。数量显示在标签上（→ 第8章）

3-1. ① 选择

  1. 1
    场景中的虚拟形象会被自动检测（有多个时用下拉框选择）。 Hierarchy 中虚拟形象很多时，也可以把虚拟形象（或其中的网格）拖放到“将头像拖放到这里”栏位来选择。 拖入网格时，与在场景中点击它相同，会直接进入“② 涂抹”。
  2. 2
    在 SceneView 中将鼠标悬停在想擦除的网格（身体等）上 候选会以高亮色发光。悬停在窗口列表的行上也会同样发光。
  3. 3
    点击确定。自动进入“② 涂抹”
💡
带 EditorOnly 标签的网格和虚拟形象不会出现在列表里。 EditorOnly 是上传时被 VRCSDK 删除的标记，因此没有擦除的意义。 隐藏的数量会显示在列表下方。用该标签排除备份副本时请留意此规则。
💡
也可以从 Inspector 开始。 给网格对象 Add Component → HoriCraft/MeshEraser 后，Inspector 会显示擦除范围的摘要和 ［编辑此网格］按钮。按下即可在选中该网格的状态下打开 MeshEraser 窗口。

3-2. ② 涂抹

  1. 1
    用左键拖动涂抹想擦除的部分 涂过的部分当场消失。
  2. 2
    擦多了就切换到“恢复”再涂回来 Ctrl+Z 也能逐步撤销。（→ 擦多了怎么办）
  3. 3
    想确认擦到哪里时，在“擦除颜色:”中选择颜色 已擦除的部分会以半透明颜色在原处重新显示，更容易用“恢复”把擦多的地方涂回来。 在 SceneView 中按 C 键也可切换（仅显示用设置，进入③时会自动恢复为擦除后的样子）。
  4. 4
    完成后点 下一步（③ 完成）
💡
相机操作（右键拖动旋转、中键拖动平移、滚轮缩放）保持 Unity 标准， 不会被工具抢占。追加的只有 Ctrl+滚轮（笔刷大小）和 Shift+滚轮（加深擦除，表面/仅外露模式时）。

3-3. ③ 完成

  1. 1
    在卡片中选择擦除方式：“彻底删除”（多边形减少、更轻量）或“菜单开关（ON/OFF）”（开关，第5章）。不选就无法完成
  2. 2
    （选开关时）设置菜单名、状态表、衣服联动。保持默认也没问题。若名称已被使用，完成时会自动加上“名称(1)”这样的编号
  3. 3
    点击 完成（确定此擦除范围）。从结果画面可以继续“涂别的地方”“打开已创建标签页”“在Play模式中确认”
  4. 4
    照常上传即可 完成后再次涂抹会作为新的擦除范围追加（并用方法）。
⚠️
开关的动作请用 Gesture Manager 或 VRChat 实机确认。 在 Unity 原生 Play 模式中，虚拟形象菜单（FX动画器）不会运行，按开关也不会有变化。 这是 VRChat 虚拟形象的通用规格，不是 MeshEraser 的问题。

4 擦除设置

在“② 涂抹”画面中自上而下排列。保持默认设置也完全可用。

4-1. 选择工具

工具用法
笔刷（默认）左键拖动涂抹擦除。适合精细调整。大小用 Ctrl+滚轮 或滑条调整
矩形 / 圆形在 SceneView 中左键拖出一个范围，松开的瞬间范围内被一并擦除。拖动中按 Esc 取消
整个擦除
（选择整个网格）		不用涂抹，把整个网格设为擦除范围。适合整体删除/开关头发部件、饰品等。“整个还原”（或Ctrl+Z）可撤销
💡
碰到一点就会擦掉。笔刷或范围哪怕只碰到三角形的一部分，整个三角形都会被删除；光标正下方必定被擦除。笔刷比多边形小也没关系。想查看多边形密度时，在显示选项中打开“显示多边形线”。

4-2. 擦除范围与深度

模式擦除的范围适用场景
穿透（默认）筒状直达最深处全部平时用这个。把衣服下的身体整块擦掉
表面朝向相机的面（含衣服下面）只想仔细擦正面时
仅外露只擦没被衣服挡住的“可见部分”隔着衣服随便涂，只有穿模部分被擦

加深擦除（cm）── 仅表面/仅外露模式

从表面再向深处擦除的深度。想连同头盔内的头发等残留在表面正下方的部分一起擦除时调大（仅限笔刷；也可用 Shift+滚轮 调整）。

  • 数值按模式分别记忆。默认：仅外露＝2cm／表面＝0cm（仅表面）
  • 在手腕、手指等较薄的部位，深度超过厚度时可能擦到背面。请在细小部位调低深度

4-3. X镜像（左右对称擦除）

开启后，只涂一侧另一侧也会对称擦除（笔刷、矩形、圆形都有效）。

  • 子选项“隐藏镜像侧的一半”可以隐藏不操作的一侧，专注于当前侧（仅显示上的变化，不影响数据）
  • 左右形状不同的网格中，找不到对应顶点的部分会保持原样

5 菜单开关（ON/OFF）与衣服联动

在“③ 完成”中选择菜单开关（ON/OFF），就不删除而是通过虚拟形象的 Expression 菜单切换涂抹部分的显示（需要 Modular Avatar，免费）。

5-1. 工作原理（不会使网格变形）

完成时会在虚拟形象正下方生成一个菜单部件（带有一套 Modular Avatar 组件的对象）。对象名＝菜单名，在 Hierarchy 里改名即改菜单名。

涂抹的部分会在构建时被切分为单独的部件，开关只是切换该部件的显示。与形态键方式不同，网格不会变形，因此不会出现边缘被拉伸的破绽。多边形仍然保留，所以不会减轻负载（想轻量化的地方请用“彻底删除”）。

💡
致熟悉 Modular Avatar 的用户：生成的只有原生 MA 组件 （MergeAnimator／Parameters／MenuItem／MenuInstaller）。 可直接在 Inspector 或菜单编辑工具中编辑，修改会反映回 MeshEraser 的UI（双向）。

5-2. 状态表的读法（★＝游戏开始时）

③和菜单标签页中的“对象（★＝游戏开始时）”表格，可以一览菜单ON/OFF各自状态下什么显示、什么隐藏。

9 常见问题

在Play模式按开关没有任何反应

Unity 原生 Play 模式中，虚拟形象菜单（FX动画器）不会运行。所有 VRChat 虚拟形象都是如此。

  1. 安装 Gesture Manager（免费）后进入Play，即可操作与游戏内相同的菜单
  2. 当然，上传到 VRChat 实机确认也可以
明明擦掉了，那里还有网格

这是另一张网格重叠在同一位置的信号。典型例子是服装自带身体部件。

  1. 打开“② 涂抹”的隐藏目标以外，在只显示目标的状态下确认是否真的擦掉了
  2. 把残留的那张网格在“① 选择”中设为目标，同样擦除

另外，带 Shape Changer 的服装可能因预览重叠而看起来有两层身体 （→ 第7章提示。上传结果是正常的）。

表面/仅外露模式擦到背面去了

“加深擦除”超过了该部位的厚度。在手腕、手指等较薄部位请调低深度（0＝和以前一样仅表面）。

有的网格/虚拟形象不在列表里

请确认是否带有 EditorOnly 标签（父对象带有时子对象也会被排除）。 EditorOnly 不会包含在上传中，因此也被排除在擦除对象外。列表下方会显示隐藏了多少个。

出现了“顶点数不一致”

涂抹之后该网格被 Blender 等重新编辑过。顶点对应关系已破坏，旧的擦除范围无法使用。

请用显示的按钮删除擦除范围并重涂。 为防止事故，旧数据绝不会被用于上传（会自动跳过）。

网格一直是擦除状态，回不来了

这是设置了擦除范围、且“关闭工具后仍显示擦除后的样子”（默认开启）生效的状态。网格本体安然无恙。

  1. 想还原 → 在已创建标签页［删除］该擦除范围
  2. 只想还原显示 → 在②的显示选项里关闭“关闭工具后仍显示～”
做了开关却没有菜单出现
  1. 确认工程中已安装 Modular Avatar（生成开关所必需）
  2. 在Play模式操作菜单需要 Gesture Manager 等
  3. 若③显示“找不到菜单部件”，说明场景里的部件被删了——用那里显示的按钮可以重建
设置了衣服联动后，游戏里衣服不见了

状态表的★（游戏开始时）在“菜单OFF”列上。OFF列是“身体显示＝衣服隐藏”的状态。 在状态表点击“★菜单ON”的列名把★移过去，就会以穿着衣服的状态开始。

显示“找不到NDMF”

用于应用删除的免费基础框架“NDMF”不在工程里 （使用 Modular Avatar 或 Avatar Optimizer 的工程不会出现此提示）。

  1. 打开 https://vpm.nadena.dev/，点“Add to VCC”注册仓库
  2. 在 VCC / ALCOM 的 Manage Project 中添加“NDMF”（安装 Modular Avatar 也会一并装上）
提示找不到虚拟形象

请确认虚拟形象根对象上有 VRC Avatar Descriptor。 删除在虚拟形象构建时应用，因此没有 Descriptor 的对象无法作为目标。 带 EditorOnly 标签的虚拟形象也会被排除在列表外。

多边形数真的会减少吗？

选择“彻底删除”的部分会减少。上传时物理移除三角形和未使用的顶点， 因此也会反映到 VRChat 性能等级的多边形计数中。

形态键（表情）、骨骼权重、UV、顶点色都会保留。 “菜单开关（ON/OFF）”只是拆分部件，不会减少多边形。

涂抹时的外观和上传后的结果一样吗？

一样。预览的删除判定与构建时完全相同 （三角形的3个顶点都被擦除时，该三角形被删除）。

唯一的例外是用“整个擦除”做成的整体开关：编辑器中外观不变，只在Play模式/上传后才呈现擦除状态（为防止加载时闪烁的设计）。

担心弄坏虚拟形象

本工具绝不改写原始网格、FBX、Prefab。 保存的只有网格上的一个小组件（擦除位置的信息），以及开关场合的菜单部件——删除它们就完全恢复原状。

不放心的话，随时可以在已创建标签页［删除］回到白纸状态。

Quest（Android）版也能用吗？

能用。删除与平台无关，PC和Quest的构建会同样应用。 只需注意开关会增加1个拆分部件的网格数（→ 5-5的注意）。

ALCOM／VCCで一覧を再読み込みし、Katachiaを0.2.0-beta.13へ更新してください。リポジトリと有効な解除キーはそのまま使えます。

顔のコピーは別のアバター／ファイル／以前の顔の目的から選び、宛先で変わる値だけを確認して適用できます。元の顔は変更しません。履歴の写真・名前を大きくし、撮影設定の開閉・スクロールを保持しました。

まず確認してほしい3つ
  1. 表情・ポーズの撮影プレビューが正しく表示されるか。なしへ戻して復旧できるか。
  2. 別のアバターへコピーする前に、宛先と変わる値が分かるか。適用を取り消せるか。
  3. 小さい画面で画像と操作欄を調整でき、保存欄が重ならないか。

01

検証用プロジェクトへ追加

普段の制作プロジェクトをコピーするか、検証用のAvatarプロジェクトを用意してください。

ボタンはPCに登録されているVCCまたはALCOMを開きます。スマホでは、このページをUnityを使うPCで開いてください。

導入手順・ボタンで開かないとき
  1. VCC／ALCOMでリポジトリの追加を確認します。
  2. 「ベータ版／プレリリースを表示」をONにします。
  3. 検証用プロジェクトのパッケージ管理でKatachiaを追加します。
  4. Unityを開き、上のメニューからHoriCraft → Katachiaを開きます。

VCCでベータが見えないとき：Settings → Packages → Show Pre-Release PackagesをON。ALCOMでは設定のプレリリース表示を確認してください。

ボタンが開かない場合は「追加用URLをコピー」し、VCCのSettings → Packages → Add Repository、またはALCOMのリポジトリ追加欄へ貼り付けてください。

02

製品版の機能を使う

テスター用キーを受け取った方は、下のボタンでコピーしてKatachiaに登録します。

•••• •••• ••••テスター用解除キー

個別DMで受け取ったキー付きリンクから開くとコピーできます。Katachiaの利用には有効な解除キーが必要です。

キーとキー付きリンクは、ほかの方へ共有しないでください。参加を希望する方は@SansanHoriへDMでご連絡ください。

登録のしかた
  1. 未登録時はKatachiaを開くとキー登録画面が出ます。登録済みの場合は「設定」を開きます。
  2. 「製品版の解除キー」に貼り付けます。
  3. 「キーを登録する」を押します。
  4. 画面上部が「製品版」になれば完了です。
期限・登録解除・別のPCについて

2026年10月13日まで製品版を試せます。期限後はキー登録画面へ戻ります。保存した顔・表情・写真は削除されません。

キー登録を外す操作は、設定の「このPCのキー登録を解除」です。誤ったキーで上書きしようとしても、現在の有効な登録は維持する設計です。

キーの登録はPCごとです。更新時の再登録は通常不要です。キーが通らない場合は、キー本文を報告画像に入れず、表示された案内をDMで教えてください。

FIRST IMPRESSION

最初は説明書を見ずに、ここまで。

目安 15〜30分

下の「やりたいこと」を、画面を見ながら試してください。操作が分からないときは無理に探し続けず、どこで迷ったかを残してからヒントを開いて大丈夫です。

01 / 調整

顔を少し変えて、元に戻してみる。

目や口を探せるか。数値やUndoの動きが予想どおりか。

迷ったらヒント

アバターを選び、「顔を整える」でメッシュと項目を選びます。少し動かしてCtrl+Z／Undoで戻します。調整した値は実際のアバターにも反映されます。

02 / 保存

気に入った顔を2段階、残してみる。

名前を付けた保存を見つけられるか。前の顔へ戻せるか。

迷ったらヒント

「今の顔を保存」で1件保存し、少し変更してもう1件保存します。「履歴」から「この顔に戻す」で値を戻せます。顔を保存すると写真も自動撮影します。

03 / 比較

2つの顔の違いを見つける。

Before／Afterの選び方が分かるか。リアルタイムと写真の違いが伝わるか。

迷ったらヒント

「顔を整える」→「保存した顔と比べる」でBeforeに保存した顔、Afterに今の顔を選び、値を動かしてみてください。比較の細かい設定にある「保存した写真で比べる」では保存時の写真を使います。撮り直す場合は「写真撮影」へ進みます。

04 / 写真

背景を選んで、1枚持ち帰る。

顔や服が見やすいか。欲しい角度をPNGにまとめられるか。

迷ったらヒント

「写真撮影」で撮る顔と並べ方を選び、「撮影」ボタンを押します。角度を増やすときは「複数撮影設定」を開きます。背景はプレビュー付近の「背景」から選べます。完成画像は別の窓で確認でき、撮影したフォルダーへ進めます。過去の保存写真の背景は、現在の背景を変えただけでは変わりません。

余裕があれば：表情作成・翌日の続き・いつもの衣装

「表情を作る」で名前を付け、「設定」→「作った表情 (.anim)」から編集できるか。シーンを保存してUnityを開き直しても、顔と写真が残るか。いつもの衣装や小さい画面でも操作しやすいか。試せる範囲で十分です。

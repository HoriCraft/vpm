先行テスト版 · 0.4.0-beta.21

MenuTool

アバターのメニュー整理と、パーツをまとめて出し入れするトグルの作成。

テスト用プロジェクトに導入

普段のプロジェクトを複製するか、新しいアバタープロジェクトを用意してください。旧Assets版MenuToolが入ったプロジェクトへの重複導入は避けてください。

VCCに追加
  1. VCCの確認画面でリポジトリを追加します。
  2. VCCの Settings → Packages → Show Pre-Release Packages をオンにします。
  3. 更新する場合はMenuToolのウィンドウを閉じてからUnityを終了し、テスト用プロジェクトの Manage Project から MenuTool 0.4.0-beta.21 を追加します。
  4. Unityを開き、HoriCraft → MenuTool から起動します。編集には、別途受け取ったMenuTool専用の解除キーを入力してください。
ALCOMで追加する／ボタンが開かない場合

リポジトリの追加画面に、次のURLを貼り付けてください。

https://horicraft.github.io/vpm/menutool-test/index.json

先行リリースが表示されない場合は、プレリリースの表示設定を確認してください。

必要な環境

Unity 2022.3、VRChat SDK Avatars、Modular Avatar、NDMF。依存パッケージが見つからない場合は、Modular Avatar / NDMFのリポジトリも追加してください。

今回の更新

「直接さわって整える」画面に更新しました。階層を開いたままの仕分け、項目の近くでの名前・アイコン編集、必要なときに開くゲーム内プレビューに対応しています。

試してほしいこと

対象アバターの選択、メニューの仕分け・並び替え、複数パーツを1つのトグルで出し入れする操作、設定からの復元。困った操作があれば、版番号と操作した項目名を添えて、リンクを送った相手へ教えてください。

この配布について

正式版・販売開始ではありません。本体は公開ダウンロードできますが、解除キーは同梱していません。処理部分はDLLで配布し、既存データとの互換性に必要な定義ファイルを同梱しています。

自動バックアップはMenuToolが扱うメニュー設定の復元用です。プロジェクト全体のバックアップにはなりません。

公開テスト版 · 1.1.0-beta.5

登録済みのPublic TestをALCOM／VCCで再読み込みし、作業を保存してUnityを閉じてから1.1.0-beta.5へ更新してください。新規トグルの生成先を Assets/HoriCraft/MeshEraser/Generated/ に変更しました。既存の MeshEraser_Generated/ 内の生成物は移動・削除しません。3構成コンパイルとファイル検証は合格しています。Unityでの新規生成・旧参照・保存再読込・メニュー動作は本人確認待ちです。UnityPackage版からの移行を実機確認済みという意味ではありません。

VCCで導入を確認する

MeshEraserを初めて入れるテスト用プロジェクトで、導入を確認するためのページです。

旧Assets版が入っているプロジェクトには追加しないでください。共存するとコンパイルエラーやGUIDの重複が発生します。旧版の自動移行は、この公開テストの対象外です。

VCCの Settings → Packages で「Show Pre-Release Packages」をオンにしてください。

VCCに追加する
  1. 下のボタンから登録し、VCCの確認画面でリポジトリを追加します。
  2. 未導入のテスト用アバタープロジェクトで Manage Project を開き、MeshEraser 1.1.0-beta.5 を追加します。
  3. Unityでコンパイル完了後、HoriCraft → MeshEraser を開きます。
ボタンで開けない場合・ALCOMで追加する場合

リポジトリ追加画面に、このURLを貼り付けてください。

https://horicraft.github.io/vpm/mesheraser-test/index.json

Unity 2022.3／VRCSDK3 Avatarsのテスト環境を使用します。NDMFが必要です。依存関係が見つからない場合は、先に次の配布元を登録してください。メニュー切替にはModular Avatarも必要です。 NDMF / Modular Avatar の配布元

本体は無料お試し版・購入者共通です。解除キーは含まれていません。購入者は手元のSTART_HERE.htmlからキーをコピーし、Unityで貼り付けてください。旧製品版ファイルによる認証は、旧Assets版の移行とは別の処理です。

このテスト版について

VCCからの実導入、Unityでの読み込み、旧版からの設定保持は確認中です。通常使用中のプロジェクトでは試さないでください。

本体とC#コードは誰でも取得できます。正式版の公開・BOOTH配布物の更新ではありません。

製品情報・利用条件

Public test build · 1.1.0-beta.5

Refresh the registered Public Test repository in ALCOM/VCC, save your work, close Unity, and update to 1.1.0-beta.5. New toggle assets are saved under Assets/HoriCraft/MeshEraser/Generated/. Existing assets in MeshEraser_Generated/ are not moved or deleted. Three compile profiles and file-level tests passed. New asset creation, old references, save/reload and menu behavior in Unity await owner testing. This does not establish native UnityPackage migration support.

Try installation with VCC

Use a test project that has never had MeshEraser installed to check installation.

Do not add this package to a project containing the old Assets edition. Coexistence causes compilation errors and GUID conflicts. Automatic migration is outside the scope of this public test.

In VCC Settings → Packages, enable “Show Pre-Release Packages”.

Add to VCC
  1. Use the button below, then confirm adding the repository in VCC.
  2. Open Manage Project for a test avatar project without MeshEraser and add MeshEraser 1.1.0-beta.5.
  3. After Unity finishes compiling, open HoriCraft → MeshEraser.
If the button does not open VCC / using ALCOM

Paste this URL into the add-repository screen.

https://horicraft.github.io/vpm/mesheraser-test/index.json

Use a Unity 2022.3 / VRCSDK3 Avatars test environment. NDMF is required. If the dependency cannot be found, register its repository below first. Menu toggles also require Modular Avatar. NDMF / Modular Avatar repository

The common package supports both trial and purchased editions. It contains no unlock key. Buyers can copy their key from their private START_HERE.html and paste it in Unity. Authentication using a legacy product file is separate from migrating an old Assets installation.

About this test build

Actual VCC installation, Unity loading and preservation of legacy settings are still under verification. Do not use your working project for this test.

Anyone can download the package and its C# code. This is not a stable release or a BOOTH download update.
